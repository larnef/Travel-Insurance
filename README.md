# Travel-Insurance

The aim of this project was to develop a pricing model for insurances within Commercial Travel. By grouping the variables into risk-homogeneous tariffs and applying GLM analysis, we successfully developed a stable pricing model for commercial travel insurance. The model's validity was confirmed through Gini coefficient optimization and risk-ratio validation, ensuring consistent performance across different groups.
